# TierLab Frontend

Interface web do TierLab desenvolvida para oferecer uma experiência moderna, rápida e escalável.

## 📋 Visão Geral

O projeto é responsável pela camada de apresentação da plataforma TierLab, consumindo APIs e exibindo dados através de uma interface intuitiva.

### Objetivos

- Alta performance
- Código limpo
- Escalabilidade
- Facilidade de manutenção
- Boa experiência do usuário
